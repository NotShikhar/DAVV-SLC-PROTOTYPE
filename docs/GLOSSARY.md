# Glossary — DAVV / IET terminology

Use these exact terms in UI copy. They are grounded in Devi Ahilya Vishwavidyalaya (DAVV) / IET practice.

| Term | Meaning |
|---|---|
| **DAVV** | Devi Ahilya Vishwavidyalaya, Indore — the university. |
| **IET** | Institute of Engineering & Technology — the engineering institute under DAVV's Faculty of Engineering. Awards **B.E.** (not B.Tech), 4 years / 8 semesters. |
| **Branch** | An engineering discipline. IET offers 9: CSE, IT, CSBS, ETC, EI, ME, CE, IPE, EEE (~690 seats). |
| **Enrollment Number** | A student's primary identity and login credential (with Date of Birth) on DAVV SIS. Format here (`DE24CS0042`) is illustrative. |
| **DTE MP** | Directorate of Technical Education, Madhya Pradesh — runs JEE-Main-based counselling that allots B.E. seats. |
| **Allotment Letter** | Seat-allotment document issued by DTE MP after counselling. |
| **CBCS** | Choice Based Credit System. Requires a minimum of **12 credits per semester** to progress. |
| **Zero Semester** | A repeated semester, applied when a student earns fewer than 12 credits. |
| **Credit** | Weight of a course. The degree here targets 160 credits (illustrative). |
| **Core / Program Elective / Open Elective** | CBCS course categories. Open electives are generic (any discipline). |
| **MST** | Mid-Semester Test. The better of MST-1/MST-2 contributes to the internal marks. |
| **Internal Assessment** | Continuous evaluation (MST + assignment + quiz), scaled to **20** = 20% of the course. |
| **External / End-Semester Exam** | University exam worth **80** = 80% of the course. |
| **Exam Eligibility** | To sit the end-semester exam a student needs **≥ 75% attendance** (per course and aggregate) and passing internal marks. |
| **Detained** | Barred from the exam for falling below the attendance/internal threshold. |
| **SGPA / CGPA** | Semester / Cumulative Grade Point Average on the UGC **10-point** scale (O=10 … F=0), credit-weighted. |
| **Supplementary (ATKT)** | Re-examination for failed/backlog courses. "ATKT" = colloquial "allowed to keep term". |
| **Revaluation** | Reassessment of an answer script after results; the best score is retained. |
| **Degree Audit** | Progress check: credits earned, backlogs, graduation eligibility. |
| **Bonafide / Character / No-Dues / Migration / Transcript / Duplicate Marksheet / Provisional / Degree** | Certificates issued via DAVV's Counter-Base Application (CBA) portal. |
| **SIS** | DAVV Student Information System (davv.mponline.gov.in) — enrolment, exam forms, records. |
| **MPOnline** | State e-governance platform used for fee payment. |
| **MP Scholarship Portal 2.0** | State post-matric scholarship portal (SC/ST/OBC) with Direct Benefit Transfer. |
| **Motto** | *Dhiyo Yonah Prachodayat* — "May that divine light illuminate our intellect." |
